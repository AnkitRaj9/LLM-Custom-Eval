# LLM-Custom-Eval
LLM Text-to-SQL BenchmarkAn automated evaluation pipeline comparing GPT-5.6 Terra and Gemini Flash Lite on real-world SQL generation tasks using actual database execution.🎯 What Was DoneInstead of judging models by tone or public benchmarks, this project benchmarks two leading LLMs on their ability to write executable SQL queries for a 4-season Indian Premier League (IPL) SQLite database across varying difficulty levels (Hard to Brutal).⚙️ How It WorksCurated Golden Dataset: A benchmark set of 20 complex questions paired with verified "gold standard" SQL queries.Zero-Vibe Evaluation: Each model generates an SQLite query based solely on the database schema and question.Live DB Execution: The generated query runs directly against the live database.Automated Verification: The returned data table is strictly compared against the expected gold result table to check for true execution accuracy.Metric Tracking: The runner records execution match, query latency (seconds), and API cost per query.📊 Final ResultsTested across 20 hard and brutal queries:ModelExecution AccuracyAvg LatencyTotal Cost (20 queries)Gemini Flash Lite85.0% (17/20)6.70s$0.00662GPT-5.6 Terra80.0% (16/20)3.23s$0.06136Key TakeawaysAccuracy: Gemini Flash Lite achieved slightly higher execution accuracy (+5%).Speed: GPT-5.6 Terra answered more than 2x faster.Cost: Gemini Flash Lite was ~9.3x cheaper to run overall.
